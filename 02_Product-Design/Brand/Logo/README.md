# StarMitra Logo Assets

Official StarMitra logo artwork. Originals stored unmodified — do not edit, recolor, or recreate.

## Current assets

| File | Variant | Format | Dimensions | Background |
|------|---------|--------|------------|------------|
| `StarMitra-Primary-Logo.png` | Primary full lockup (emblem + wordmark + tagline) | PNG | 1781×1750 | Transparent |
| `StarMitra-Brand-Mark.png` | Brand mark / emblem only | PNG | 1686×1258 | Transparent |

## Naming convention

```text
StarMitra-Primary-Logo.{ext}     # full lockup
StarMitra-Brand-Mark.{ext}       # emblem-only mark
StarMitra-Logo-Reversed.{ext}    # reversed variant (if supplied)
StarMitra-Logo-Mono.{ext}        # monochrome (if supplied)
StarMitra-Lockup-NoTag.{ext}     # without tagline (if supplied)
```

## Usage rules

- Do not modify, recolor, distort, stretch, crop, or redraw the logo; preserve proportions, colors, clear space, aspect ratio.
- PNGs are transparent — designed for light backgrounds; dark surfaces need a light container or a reversed variant (not yet provided).
- Raster files are not upscaled beyond source resolution; vector becomes preferred if supplied.
- Full rules: `../Brand-Guidelines/STARMITRA-BRAND-BASELINE-v1.0.md`; asset register: `../ASSET-INVENTORY.md`; verified palette: `../Colors/STARMITRA-COLOR-SYSTEM.md`.
